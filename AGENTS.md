# StickTwist working rules

- Never process, encode, synthesize or render media locally or on self-hosted runners.
- Use only standard free GitHub-hosted Linux runners in this public repository.
- Never add paid APIs, billing accounts, larger runners, Actions artifact storage or caches.
- Never upload to YouTube without the owner's approval of the exact episode bundle and visibility.
- Keep preview releases and upload ledger as unpublished drafts.
- Never commit credentials. Preserve fail-closed approval, hash and channel checks.
- Run meaningful text/integrity tests locally; end-to-end media checks run in Actions.
