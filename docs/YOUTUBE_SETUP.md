# Подключение YouTube — без платных услуг

Загрузки отключены, пока не заданы секреты и `YOUTUBE_UPLOAD_ENABLED=true`. Это дополнительный выключатель, а не одобрение конкретного ролика. Не включайте его до проверки кода и первого MP4.

## Канал

Создайте канал **StickTwist** в своём YouTube-аккаунте. Предпочтительный handle `@StickTwist`, запасной `@StickTwistStories`; их доступность не проверена. Описание: **Original stickman stories. Unexpected twists. All stories are fictional.**

Проект не создаёт канал автоматически и не изменяет существующий канал. Сохраните точный channel ID вида `UC...` из YouTube Studio / настроек канала.

## Бесплатный доступ к API

1. Откройте Google Cloud Console под владельцем канала и создайте проект StickTwist. **Не подключайте платёжный аккаунт, пробный кредит, карту или платный API.** Если интерфейс требует billing, остановитесь: это не разрешено бюджетом.
2. Включите только **YouTube Data API v3**. Настройте Google Auth Platform / OAuth consent для личного использования, укажите себя как тестового пользователя при статусе Testing.
3. Создайте OAuth client типа **Desktop app**. Скачайте клиентский JSON в защищённую локальную папку. Не кладите его в репозиторий.
4. Для входа можно выполнить `python -m sticktwist.oauth_setup --client <путь-к-JSON> --output token.youtube.json` в Python с `google-auth-oauthlib==1.2.2`. Это только авторизация через браузер, без обработки видео. Дайте согласие только своему проекту. Выберите именно нужный канал, особенно при наличии Brand Account.
5. В GitHub → StickTwist → Settings → Secrets and variables → Actions → Secrets добавьте:
   - `YOUTUBE_TOKEN_JSON`: содержимое `token.youtube.json`, включающее refresh token и OAuth client.
   - `YOUTUBE_CHANNEL_ID`: точный ID нужного канала.
6. В разделе Variables добавьте `YOUTUBE_UPLOAD_ENABLED` со значением `true` только когда хотите разрешить возможность ручной загрузки. Пароли, токены и JSON не присылайте в чат.

OAuth требует два scope: `youtube.upload` для разрешённой загрузки и `youtube.readonly` для проверки правильного канала. Сервисные аккаунты для обычного личного канала не используются. В Testing refresh token для таких scope может истекать через семь дней; потребуется повторная авторизация либо корректный перевод OAuth-приложения в Production по правилам Google. Производственный статус OAuth и аудит YouTube API — разные процедуры.

## Одобрение каждого ролика

Откройте неопубликованный preview draft в Releases. Просмотрите MP4, сценарий, субтитры и metadata.json. Скопируйте SHA256 **ZIP**, а не MP4. В Actions → Approve YouTube upload заполните:

- `preview_tag`: tag вида `preview-2026-10-26-<run_id>-<attempt>` из черновика;
- `episode_id`: например `my-best-friend-sold-my-ps5`;
- `bundle_sha256`: 64 символа из таблицы предпросмотра;
- `visibility`: private, unlisted или public — выберите сознательно;
- `confirmation`: `APPROVE my-best-friend-sold-my-ps5 <полный SHA256> private` для частной загрузки.

Нажать Run workflow должен владелец репозитория. Само подключение OAuth, создание очереди, успешная сборка, время в календаре, комментарий постороннего или отсутствие ответа **не являются одобрением**.

После загрузки проверьте фактическую видимость в YouTube Studio. Ограничения аккаунта/API могут не позволить публичную видимость. На момент подготовки официальные страницы Google расходятся в описании private-only ограничения для непроверенных API-проектов; не рассчитывайте на публичный автоматический выпуск до фактической проверки своего проекта. Код записывает запрошенную и фактическую видимость, но не пытается обходить ограничения.

## Восстановление и отключение

- Чтобы отключить загрузки: удалите переменную `YOUTUBE_UPLOAD_ENABLED` либо задайте `false`.
- Чтобы остановить подготовку роликов: Actions → Build review videos → Disable workflow.
- При потере доступа отзовите OAuth в аккаунте Google, удалите секрет GitHub и авторизуйтесь заново.
- При ошибке после создания `*.pending.json` проверьте YouTube Studio вручную. Не удаляйте pending claim и не повторяйте загрузку, пока не установите, что предыдущая попытка не создала видео.
- Вы можете опубликовать одобренный MP4 через YouTube Studio вручную вместо API. Это не требует доступа API; одобрение содержания всё равно необходимо.
